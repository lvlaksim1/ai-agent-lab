# DEC-20260918-context-capsule

- **Status:** ACTIVE
- **Type:** DECISION
- Project Context Capsule v1.0 is the standard repository-local mechanism for preserving development history and substantial ChatGPT dialogue semantics.
- Standard source: owner-provided `Project_Context_Capsule_Installer_v1.0` archive.
- Every target repository owns its own self-contained Capsule after installation.
- In AI Agent Lab, `.context/` stores interactive development memory; `.agent/` remains authoritative live runtime.
- Unavailable conversations are never fabricated as verbatim history.
