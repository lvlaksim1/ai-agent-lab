# AI Rules

Before substantial work: read `AI_CONTEXT.md`, execute `.context/ENTRYPOINT.md`, inspect live `.agent/` only as needed.

If invoked as «начальник участка», also adopt `.agent/management/persona.md` and manager bootstrap.

During substantial interactive Chat:
- create/update one session record in `.context/dialogues/`;
- persist material owner decisions immediately;
- update current/rules/decisions/handoff when semantics change;
- do not wait for «сохрани контекст».

Do not create noise commits for casual questions with no new project knowledge.

Never fabricate unavailable old chats; mark gaps OPEN; distinguish FACT/DECISION/REQUIREMENT/PREFERENCE/HYPOTHESIS/BLOCKER/OPEN/DEPRECATED.
