# Начальник участка — обзор DEC-018

**Объект:** `ios-research-runtime`  
**Решение:** `KEEP_COURSE`  
**Здоровье:** `ORANGE`

## Обстановка

Смена №43 Михалыча потеряла runtime. Последний сохранённый heartbeat — `2026-09-19T03:37:49Z`, stale boundary — `03:40:49Z`; stale guard безопасно снял production lease в `03:46:01Z`. На момент последнего подтверждённого действия Михалыч уже опубликовал стартовый доклад и собирался реализовать ранее локализованное source/rebuilt NXSB evidence wiring.

Техническое направление не опровергнуто: decoded source reader и serializer уже локализованы, а предыдущая независимая приёмка подтверждает, что структурное сравнение должно выполняться на decoded image layer через `disk.OpenWithOffset`, а не raw DMG. Два последних no-progress результата связаны прежде всего с потерями runtime вокруг одной узкой границы реализации, а не с доказанным тупиком курса.

## Управленческое решение

Курс сохраняется. `DIR-011` остаётся активной: после независимого ОТК следующая производственная смена должна реализовать уже локализованный read-only source/rebuilt NXSB snapshot wiring, затем пройти существующие Windows gates и exact E2E. APFS writer нельзя менять до появления причинного structural evidence.

Решение владельца не требуется. STOP не вводится. Менеджер производственную смену не запускает.

**Decision:** `DEC-018`.
