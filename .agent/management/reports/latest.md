# Начальник участка — обзор DEC-028

**Объект:** `ios-research-runtime`  
**Решение:** `CHANGE_COURSE`

## Обстановка

Производство `idle`, активного работника нет. ОТК смены №51 завершён, но target edit снова не был сохранён. Серия достигла 12 consecutive no-progress смен. Это уже не неопределённость APFS-архитектуры: bounded decoded source/rebuilt NXSB wiring известен, а смены повторно теряют runtime до сохранения целевого изменения.

## Управленческое решение

`DIR-012` заменена на `DIR-013`. Следующая смена обязана начать не с повторной разведки, а с non-truncating GitHub contents/raw/blob retrieval/mutation route и первым substantive action сохранить минимальный уже локализованный wiring edit. Сразу после target mutation — checkpoint и heartbeat. Затем только необходимая очистка wrong-layer C# abort и обязательные Windows gates/exact E2E.

Если non-truncating mutation route действительно недоступен, сменщик должен сохранить точную ошибку доступа/инструмента и остановиться, а не тратить ещё одну смену на повторный анализ. Тогда появится конкретное основание для следующей эскалации.

APFS writer остаётся заморожен до causal structural evidence. Решение владельца, STOP и перевод объекта сейчас не требуются.
