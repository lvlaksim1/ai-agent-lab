# Начальник участка — обзор 8

**Объект:** `ios-research-runtime`  
**Решение:** `KEEP_COURSE`  
**Здоровье:** `YELLOW`

## Обстановка

Производство продолжило подтверждённое продвижение. Ошибка Win64 page-rounding/address corruption закрыта exact Windows E2E; XNU теперь доходит до BSD root `md0`. Текущий устойчивый blocker — rebuilt recovery APFS, который mountroot отвергает с error 79.

Последняя локализация полезно сузила границу: идентификационные свойства APFS переносятся, но существенная часть NX/APFS superblock/checkpoint metadata при rebuild синтезируется заново. Доказательства пока недостаточно, чтобы безопасно назвать одно конкретное несовместимое поле.

## Управленческое решение

Курс сохраняется. Следующая работа должна сделать ограниченное структурное сравнение original/rebuilt recovery APFS/DMG и доказать первое причинно значимое несовместимое поле до изменения writer semantics. Proof gates не ослаблять; к старой SPTM/address ветке без нового evidence не возвращаться.

STOP, перевод объекта, новая директива и решение владельца не требуются.

**Decision:** `DEC-008`.
