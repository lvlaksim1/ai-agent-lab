# Начальник участка — обзор DEC-031

**Объект:** `ios-research-runtime`  
**Решение:** `CHANGE_COURSE`  
**Здоровье:** `ORANGE`

## Обстановка

Производство `idle`/`NO_WORKER`. Независимый ОТК закрыл смену №56 `APPROVED 5/10`, но target mutation снова не была сохранена. Четыре подряд результата без подтверждённого проектного прогресса показывают, что технически локализованная правка упирается уже не в APFS-архитектуру, а в неопределённость маршрута безопасной записи большого `main.go`.

## Управленческое решение

Курс исполнения ужесточён до `DIR-014`. Следующая смена не исследует новые способы записи и не повторяет NXSB-анализ. Она получает точную полную ревизию `main.go` через non-truncating GitHub contents/raw/blob route, сохраняет точный blob SHA, вносит только уже локализованный decoded source/rebuilt NXSB wiring и записывает файл через contents/CAS against that SHA. Сразу после target commit — checkpoint и heartbeat.

Если этот точный маршрут после одного authoritative re-read/reconcile не работает, смена обязана сохранить конкретную API/tool/access ошибку и остановиться; это станет доказательством для следующей управленческой эскалации. После успешного wiring — убрать wrong-layer C# abort и пройти обязательные Windows gates/exact E2E.

APFS writer остаётся заморожен до причинного structural evidence. STOP, перевод объекта и решение владельца сейчас не требуются.
