# Начальник участка — обзор 9

**Объект:** `ios-research-runtime`  
**Решение:** `HOLD_EVIDENCE_BLOCK`  
**Здоровье:** `BLOCKED`

## Обстановка

Производство сейчас корректно простаивает: production state `idle`, production wake не pending. Подтверждённая граница прежняя — exact Windows E2E дошёл до BSD root `md0`, rebuilt recovery APFS падает на `mountroot error 79`.

Причинное свидетельство для следующей writer-правки по-прежнему недоступно: нужен exact E2E artifact/full job log либо эквивалентный компактный structural dump source-vs-rebuilt NX/APFS/checkpoint metadata. Без него новая смена повторит уже выполненную диагностику или будет вынуждена гадать.

## Управленческое решение

Сохраняю `BLOCKED` и не будю производство. APFS writer и proof gates не трогаем. Перевод и emergency STOP не нужны.

Решение владельца остаётся необходимым: дать production доступ к exact E2E artifact/full log или передать эквивалентный structural dump, после чего можно возобновить доказательную локализацию первого несовместимого metadata field.

**Decision:** `DEC-009`.

## Что требуется от владельца

Нужно разрешить создать диагностический APFS evidence channel в Windows E2E: после rebuild сохранить компактный structural dump исходного и rebuilt APFS/NX/checkpoint metadata и затем возобновить производственные смены на основании этого evidence.

## Зачем это нужно

Сейчас загрузка уже дошла до `BSD root: md0`, но rebuilt recovery APFS падает на `mountroot error 79`. Доступный artifact содержит логи, но не содержит структурных данных APFS, достаточных для доказательства первого несовместимого поля. Новый диагностический channel даст работникам недостающий причинный материал без ослабления proof gates и без изменения APFS writer наугад.

После разрешения производство можно снова разбудить автоматически с задачей сначала получить structural evidence, а уже затем продолжить исправление.

## Варианты ответа

1. **Рекомендуемый:** «Разрешаю добавить диагностический APFS evidence channel и возобновить производство.» — начальник создаст доказательный маршрут, поставит работу в очередь и бригада продолжит сама.
2. «Не менять E2E. Я сам предоставлю structural dump APFS.» — производство останется в ожидании, пока вы не передадите dump.
3. «Оставить проект заблокированным.» — новых производственных смен по этому объекту не будет до нового распоряжения.
