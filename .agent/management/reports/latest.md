**Объект:** `ios-research-runtime`

## Обстановка

Производство `idle`, активного работника нет. Независимый ОТК смены №50 завершён; target edit до runtime loss сохранён не был. Серия no-progress достигла 11 смен, поэтому стоимость повторения уже существенная.

При этом корректирующий курс уже задан `DIR-012`: повторная архитектурная разведка запрещена, следующий сменщик должен начать с уже локализованного bounded decoded source/rebuilt NXSB wiring edit, сохранить его и немедленно checkpoint-нуть результат.

## Управленческое решение

Курс не меняю и новой директивы не выпускаю. `DIR-012` остаётся обязательной. После wiring/checkpoint допускается только необходимая очистка wrong-layer C# abort и обязательные Windows gates/exact E2E. APFS writer остаётся заморожен до первого причинно доказанного structural mismatch.

Если следующая смена при исправном runtime снова не сохранит этот bounded edit, следующий management review должен менять стратегию исполнения, а не повторять ту же инструкцию.

Решение владельца, STOP или перевод объекта не требуются.
