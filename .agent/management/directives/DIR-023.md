## Direction

1. Preserve independent OTK review of shift 91 as the first relay event; do not bypass or fabricate review evidence.
2. Do not repeat broad APSB/XID/checkpoint architecture discovery. The next product action remains the already-localized APSB `modificationTime -> existing FixedTime` preservation.
3. Do not depend on one tool response containing the entire target file. Retrieve the authoritative target preimage deterministically in bounded non-overlapping chunks/ranges (or an equivalent exact Git blob representation), assemble it without normalization, and verify that the assembled preimage corresponds to the authoritative current blob SHA before any write.
4. Apply only the localized FixedTime preservation edit to that verified preimage. Preserve every other byte/text region unchanged.
5. Write by whole-file replacement using the authoritative current blob SHA as the CAS guard. If the branch/blob changed, abort the write, re-read and re-verify; never overwrite a newer preimage.
6. If exact reconstruction or SHA verification cannot be established with available GitHub primitives, do not mutate the target. Persist the exact retrieval/verification defect and the smallest evidence needed for the next shift instead of retrying the same truncated path.
7. After a successful mutation, immediately checkpoint the exact target commit SHA, then run focused tests, Windows gate, and exact Windows E2E. Consume terminal evidence before any further writer change.
8. Keep unrelated APFS writer semantics frozen. Do not reopen XID/checkpoint or speculative MetaCrypto without new discriminating evidence.

## Success criterion

The exact authoritative target preimage is reconstructed and verified despite response truncation, the bounded APSB FixedTime preservation is committed through a CAS-safe whole-file write, its exact target SHA is checkpointed, and the established focused-tests -> Windows-gate -> exact-Windows-E2E chain is executed; or, if reconstruction is impossible, a concrete authoritative retrieval defect is persisted without target mutation.
