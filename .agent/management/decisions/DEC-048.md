## Evidence

The blocker is therefore not absence of a CAS primitive: the safe route is to fetch the complete current file, make exactly one deterministic localized replacement in memory, and submit the complete result with `update_file` against that exact blob SHA. This preserves CAS semantics while avoiding any search for alternate write mechanisms.

## Decision

Before writing, it must prove exactly one expected old fragment match; after writing, checkpoint the returned target commit SHA immediately. If the full current file cannot be fetched completely or the expected fragment does not match exactly once, stop and persist that concrete evidence rather than rediscovering architecture.
