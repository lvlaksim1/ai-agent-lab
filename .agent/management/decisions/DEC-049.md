## Evidence

Production is idle after OTK finalized shift 76. Management state records five consecutive no-progress shifts and the latest shift was CORRECTED because its immutable Reporting v2 start report was malformed before any target work. The technical route in DIR-020 remains valid, but repeated report-contract failures are consuming shifts before the already-localized target mutation can occur.

The authoritative `.agent/reporting.md` gives the exact literal start-report template and names the shared marker contract. Therefore the next shift must not compose an approximate report and discover the defect only after immutable publication.

## Decision

Supersede DIR-020 with DIR-021. Preserve the same bounded whole-file CAS snapshot-preservation technical course, but add a deterministic pre-publication Reporting v2 preflight: construct the report from the exact canonical literal labels, validate the complete candidate against the shared report contract before creating the immutable file, then still perform the required post-commit re-read and exact-commit Agent Runtime Check. Only terminal SUCCESS unlocks target mutation.

No owner decision is required. Product scope, Definition of Done and APFS-writer freeze remain unchanged.
