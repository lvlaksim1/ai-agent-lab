# DEC-052 — KEEP_COURSE

object_id: ios-research-runtime
decision: KEEP_COURSE

## Assessment

Shift 81 produced substantial, independently accepted progress. The exact Windows E2E still fails at APFS mountroot error 79, but the new checkpoint evidence ruled out a simplistic XID repair: source and rebuilt active checkpoint XIDs differ, while the pinned writer intentionally uses a static formatXID=1 architecture. Therefore the XID mismatch alone is not causal proof and does not justify changing writer semantics.

The control-plane startup defect addressed by DIR-022 is no longer the active blocker. The next discriminating step is already concrete and evidence-backed: compare source/rebuilt APSB semantics (FSIndex, feature masks, meta-crypto state, tree types, volume flags, role/group, root/revert/snapshot metadata), then permit only the nearest mutation justified by an observed semantic difference.

## Decision

Keep the current causal debugging course. Do not reopen settled snapshot-preservation work and do not mutate APFS writer semantics based only on checkpoint XID. Production should continue directly with APSB semantic comparison and consume that evidence before selecting any writer repair.

No owner decision or production STOP is required. DIR-022 remains active insofar as its unchanged runtime/reporting invariants and evidence-first constraints apply; its control-plane repair objective is considered satisfied.
