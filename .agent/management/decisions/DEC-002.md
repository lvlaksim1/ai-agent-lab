# DEC-002 — KEEP_COURSE

Object: ios-research-runtime
Decision: KEEP_COURSE
Health: YELLOW

## Управленческий вывод

После предыдущего обзора производство продолжило давать проверяемое диагностическое продвижение без изменения root logic и без ослабления proof gates. Смена 9 установила, что X2 уже содержит 0x12ed0000 при входе в callee, а LR=0xfffffff0070b3a58 переносит точку поиска к caller около 0x...0b3a54. Это исключает дальнейшее бессмысленное расширение линейного trace-окна внутри 0x...0d76xx.

Следующий технически обоснованный шаг уже сформирован: независимый ОТК смены 9, затем exact E2E artifact для commit 24c320627651c84dd1d0d4f923ec301cb855d642 и восстановление подготовки X2 перед BL. Root-cause patch допустим только после доказательства контракта offset-vs-absolute-PA.

## Решение

Курс не менять. Новую директиву не выпускать. Производство не останавливать. Решение владельца не требуется.

Контрольная точка следующего manager review: наличие/качество evidence по caller-side producer X2 и отсутствие повторного диагностического движения без нового знания.
